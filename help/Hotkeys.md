# 2htm Hotkeys

The keys of the 2htm dialog, listed three ways. Each Alt key is the letter underlined in its control's label, so a screen reader reads it with the control. OK and Cancel have no letter: Control+Enter is OK and Escape is Cancel, from any control, and Enter is OK except on a button. The dialog is built with the Homer Lbc classes, so every text field also has the Lbc editing keys; Help (F1) lists them.

## By key

- Alt+B — Browse local source
- Alt+C — Choose output directory
- Alt+Control+2 — open the 2htm dialog from anywhere (the desktop shortcut)
- Alt+D — Default settings
- Alt+F — Force replacements
- Alt+H — Help
- Alt+I — Strip images
- Alt+O — Output directory
- Alt+P — Plain text
- Alt+S — Source paths
- Alt+U — Use configuration
- Alt+V — View output directory
- Control+Enter — OK, from any control
- Enter — OK: start converting
- Escape — Cancel, from any control: close without converting
- F1 — Help
- F11 — check for a newer version, from any control
- F7 — list the dialog's controls, and move to the one chosen
- Shift+F1 — say the focus tip for the current field
- Shift+F10, then 2 — Convert via 2htm, on a file in File Explorer

## By command

- Browse local source — Alt+B
- Cancel — Escape
- Check for a newer version — F11
- Choose output directory — Alt+C
- Convert via 2htm, in File Explorer — Shift+F10, then 2
- Default settings — Alt+D
- Force replacements — Alt+F
- List the controls — F7
- Help — Alt+H or F1
- OK — Enter, or Control+Enter from any control
- Open the dialog from anywhere — Alt+Control+2
- Output directory — Alt+O
- Plain text — Alt+P
- Say the focus tip — Shift+F1
- Source paths — Alt+S
- Strip images — Alt+I
- Use configuration — Alt+U
- View output directory — Alt+V

## In tab order

The dialog is in bands, rows read left to right, in this order:

1. Source paths — Alt+S
2. Browse local source — Alt+B
3. Plain text — Alt+P
4. Strip images — Alt+I
5. Output directory — Alt+O
6. Choose output directory — Alt+C
7. Force replacements — Alt+F
8. Use configuration — Alt+U
9. View output directory — Alt+V
10. Default settings — Alt+D
11. Help — Alt+H or F1
12. OK and Cancel, alone at the bottom right: Control+Enter is OK and Escape is Cancel, from any control

## Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because "elevate" sounds like "eleven". Alt+Control+2 belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts, and 2 is the first character of 2htm. The same 2 is the access key of Convert via **2**htm in File Explorer. Strip images takes I, from images, because S already belongs to Source paths. Word keeps Alt+Control+2 for its Heading 2 style while it has focus.
