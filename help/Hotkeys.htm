2htm Hotkeys

The keys of the 2htm dialog, listed three ways. Each Alt key is the letter underlined in its control’s label, so a screen reader reads it with the control. OK and Cancel have no letter: Enter is OK, Control+Enter is OK from any control, and Escape is Cancel. The dialog is built with the Homer Lbc classes, so every text field also has the Lbc editing keys; Help (F1) lists them.

By key

  • Alt+B — Browse source
  • Alt+C — Choose output
  • Alt+Control+2 — open the 2htm dialog from anywhere (the desktop shortcut)
  • Alt+D — Default settings
  • Alt+F — Force replacements
  • Alt+G — Guide: open the full guide, then return to the dialog
  • Alt+H — Help
  • Alt+I — Strip images
  • Alt+L — Log session
  • Alt+O — Output directory
  • Alt+P — Plain text
  • Alt+S — Source files
  • Alt+U — Use configuration
  • Alt+V — View output
  • Control+Enter — OK, from any control
  • Enter — OK: start converting
  • Escape — Cancel: close without converting
  • F1 — Help
  • F11 — check for a newer version
  • F7 — list the dialog’s controls, and move to the one chosen
  • Shift+F1 — say the focus tip for the current field
  • Shift+F10, then 2 — Convert via 2htm, on a file in File Explorer

By command

  • Browse source — Alt+B
  • Cancel — Escape
  • Check for a newer version — F11
  • Choose output — Alt+C
  • Convert via 2htm, in File Explorer — Shift+F10, then 2
  • Default settings — Alt+D
  • Force replacements — Alt+F
  • Guide — Alt+G
  • List the controls — F7
  • Help — Alt+H or F1
  • Log session — Alt+L
  • OK — Enter, or Control+Enter from any control
  • Open the dialog from anywhere — Alt+Control+2
  • Output directory — Alt+O
  • Plain text — Alt+P
  • Say the focus tip — Shift+F1
  • Source files — Alt+S
  • Strip images — Alt+I
  • Use configuration — Alt+U
  • View output — Alt+V

In tab order

  1. Source files — Alt+S
  2. Browse source — Alt+B
  3. Output directory — Alt+O
  4. Choose output — Alt+C
  5. Strip images — Alt+I
  6. Plain text — Alt+P
  7. Force replacements — Alt+F
  8. View output — Alt+V
  9. Log session — Alt+L
  10. Use configuration — Alt+U
  11. The buttons: OK (Enter), Guide (Alt+G), Default settings (Alt+D), Cancel (Escape) and Help (Alt+H)

Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because “elevate” sounds like “eleven”. Alt+Control+2 belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts, and 2 is the first character of 2htm. The same 2 is the access key of Convert via 2htm in File Explorer. Strip images takes I, from images, because S already belongs to Source files. Word keeps Alt+Control+2 for its Heading 2 style while it has focus.
